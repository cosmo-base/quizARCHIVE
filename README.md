# Cosmo Base 毎日宇宙クイズ 過去問練習サイト（V0モック）

参加者向けの過去問サイトのUI/UXを、モックデータで確認するためのプロトタイプです。
要件は [docs/requirements.md](docs/requirements.md)（要件定義書 v1.0）に基づきます。

> **V0モックです。** 問題・正答率・利用者はすべて仮データです。認証・永続保存・全体集計は行わず、操作内容はこのブラウザの localStorage にだけ保存されます。

## 起動

```bash
pnpm install
```

```bash
pnpm dev
```

`http://localhost:3000` を開きます。ほかのコマンド：

- `pnpm build`：本番ビルド
- `pnpm typecheck`：型チェック
- `pnpm test`：受入条件のチェック（`tests/rules.test.ts`）

## デモの操作

- **ログイン（モック）**：ヘッダーの「ログイン」から、デモ用の利用者（初級／中級・合格2回／上級／専門家・合格17回）を選びます。
- **デモ操作**（ヘッダーの点線ボタン）
  - 回答保存・誤り報告・一覧読み込みの失敗を再現
  - 回答中の回の残り時間を15秒にして時間切れを確認
  - 日付変更の再現（重複防止の履歴だけリセット）
  - 難易度の再判定間隔を10件／100件に切り替え
  - デモを初期状態に戻す
- 単問詳細の下にある「デモ専用：内部の集計値」で、基本／復習回答数・SNS正答率・判定境界を確認できます（参加者向けの表示ではありません）。

## 未決事項（TBD）の仮置き

V0では次の仮の値・挙動にしています。最終決定ではありません。

| TBD | V0での仮置き |
|---|---|
| TBD-01 | 練習の問題数は5／10／20／40問。時間制限は「なし／個人レベルの目安／10・20・30・60分」。練習の時間切れも選択済み回答を集計。ゲストの目安は初級基準 |
| TBD-02 | 版ごとに統計版を分ける。復習は現行版で出題し、結果では出題時の版を表示 |
| TBD-03 | 分野は仮の5分野。各分野8問（40÷5）を確保し、足りない難易度は1段階下→さらに下→上の順で補う。分野内で不足したら他分野で補う |
| TBD-04 | セットは開始時に記録。練習とテストで履歴を共有。日界は日本時間0時。ゲストはブラウザ単位 |
| TBD-05 | 期限は開始時に確定し、端末の時計ではなく期限との比較で自動確定。未同期の選択は終了時に再送してから確定。無期限の練習は自動確定しない |
| TBD-06 | ログインはデモ用利用者の選択。ゲストの履歴は保存しない |
| TBD-07 | 次の再判定境界は「前回判定件数＋現在の間隔」 |
| TBD-09 | 訂正のお知らせは、ブラウザのセッションごとに起動後最初の画面で1回表示 |

## 構成

```
app/                 画面（Next.js App Router）
components/kit       共通UI（ダイアログ・入力・トースト等）
components/quiz      クイズ用の部品（選択肢・解説・誤り報告・星など）
components/shell     ヘッダー・ログイン（モック）・デモ操作
lib/domain           ルール・出題生成・採点／集計／認定（モックの「サーバー処理」）
lib/mock             仮の問題データと初期データ
lib/store            ブラウザ内ストア（本番ではAPIに差し替え）
tests                受入条件のチェック
```

採点・集計・認定は `lib/domain/actions.ts` に集約しています。本番ではAPI側で同じ検証を行い、ブラウザの値だけで得点・合格・難易度を更新しない前提です。

## 注意

- Google Apps Script（GAS）のコードはこのリポジトリに含めません（`.gitignore` で `*.gs`・`appsscript.json`・`.clasp.json` を除外）。
- 管理者画面は対象外です（別サイトまたは既存のQuiz Managerで扱う想定）。
